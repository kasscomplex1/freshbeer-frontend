What this is

Working prototype of a brewery-to-glass freshness platform. Every batch gets a "Born On" date. Every outlet gets a freshness score. Every scan proves the chain. Built for the Disruption Lab workshop.

How it works

  1. QR code on every bottle: https://fresh.fauluhost.co.tz/scan/?batch=B-XXXX&outlet=O-XXXX
  2. Customer scans with phone camera → opens this page
  3. Picks bottle age category → submits
  4. Sees freshness band (FRESH/GOOD/MOVE IT) + the outlet's score updates live
  5. Outlets with high scores get the "Fresh Serve Certified" badge to display

Architecture

  • Frontend (this site): Cloudflare Pages at fresh.fauluhost.co.tz — global CDN, free, HTTPS included
  • Backend API: Python on VPS at api.fauluhost.co.tz:8090 — scan recording + scoring engine
  • Database: SQLite — fast for thousands of scans, easy to scale later
