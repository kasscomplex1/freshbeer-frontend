The Chain

  1. QR on every bottle points to https://fresh.quick.co.tz/scan/?batch=B-XXXX&outlet=O-XXXX
  2. Customer scans → opens the mobile page → picks bottle age category
  3. Submits → server returns FRESH / GOOD / MOVE IT + outlet score
  4. Outlets with high scores earn the Fresh Serve Certified badge to display
  5. Distribution discipline becomes a marketing asset, not a cost

Architecture

  • Frontend — Cloudflare Pages at fresh.quick.co.tz. Global CDN. HTTPS. Free.
  • Backend API — Python on VPS at api.fauluhost.co.tz:8090. Scan recording + scoring engine.
  • Database — SQLite. Fast for thousands of scans, easy to scale.
  • Score formula — 50% fresh % · 30% average age (younger better) · 20% recency of last scan.

Status

Working prototype. Ready for workshop demo. Seed data in place — register batches and outlets from the API, scan to populate the leaderboard.
